# Student Task Manager

## 1. Project Description

Student Task Manager is a simple web application designed to help
students organize and manage their academic tasks.

The application allows users to add tasks and delete tasks from a
task list through a simple and user-friendly interface.

---

## 2. Project Objectives

The objectives of the project are to:

- Create a simple task management website for students.
- Allow users to add tasks.
- Allow users to delete tasks.
- Practice web development using HTML, CSS and JavaScript.
- Practice project management using Git and GitHub.
- Demonstrate the use of issues, milestones, branches, commits and
  pull requests.

---

## 3. Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub

---

## 4. Features

The Student Task Manager currently provides the following features:

- Student task management homepage
- Add new tasks
- Delete existing tasks
- Empty task validation
- Simple and clean user interface
